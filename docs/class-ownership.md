## Responsibilities

1. Each member must implement and maintain their assigned classes.
2. Each member must validate inputs and prevent invalid state changes.
3. Each member must understand and explain their assigned classes.
4. Members must coordinate when their classes interact with other classes.
5. All members must participate in testing and debugging.
6. Changes must be committed and pushed to the shared GitHub repository using the agreed branching and commit conventions.
